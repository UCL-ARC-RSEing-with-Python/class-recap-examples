# Classwork "Recap" Examples

This repository contains small code fragments that can be used to demonstrate a common theme or problem that was observed in submissions to homework or classwork exercises.
Each folder contains code that will demonstrate a few (potentially related) concepts that might have appeared during marking, along with it's own `README` details what that folder is aimed to demonstrate.

Teachers should be able to use the code fragments to demonstrate the corresponding problems and how to work around them.
